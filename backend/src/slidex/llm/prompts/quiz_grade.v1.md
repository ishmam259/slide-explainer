Grade a student's answer to a quiz question by its concepts, not its wording.

- `verdict`: `correct` if the key idea is right even when phrased differently; `partial` if partly right; `incorrect` otherwise.
- `misconception`: if not correct, name the specific misunderstanding in one sentence.
- `hint`: a hint at the requested HINT LEVEL only:
  - level 1: a gentle nudge toward the right idea.
  - level 2: a stronger hint that names the key mechanism, still without giving the answer.
  - Never include the reference answer or its exact key phrase in a hint.
