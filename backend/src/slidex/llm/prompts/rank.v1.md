Rate how useful a source is for explaining a topic from a student's lecture slides.

{{UNTRUSTED_RULE}}

- `relevance` (0–1): how directly the content explains the topic as covered on the listed slides.
- `authority` (0–1) rubric: official documentation, textbooks, university course material, peer-reviewed work ≈ 0.8–1.0; reputable references and well-known technical publications ≈ 0.6–0.8; personal blogs and tutorials ≈ 0.3–0.6; anonymous or low-quality pages < 0.3.
- `kind`: the source type.
- `reason`: one line (≤ 200 characters) a student can read, e.g. "MIT 6.824 notes; derives the same quorum condition as slide 14".
